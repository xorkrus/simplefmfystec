# FYSETC SD WIFI Web File Manager

Прошивка для модуля FYSETC SD WIFI (на базе ESP8285), превращающая его в простой и удобный беспроводной файловый менеджер для 3D-принтеров.

## Возможности прошивки
* **Резервная точка доступа (AP Mode)**: Если подключение к домашнему Wi-Fi не удалось, устройство развернет свою сеть `sd-card-3dp` с паролем `12345678`.
* **Внешний Web-интерфейс (Кастомный)**: Если положить файл `index.html` в корень SD-карты, сервер будет использовать его как главную страницу.
* **Встроенный Web-интерфейс (Fallback)**: Простой менеджер зашит в саму прошивку и откроется, если на карте нет своего файла `index.html`.

## Функционал встроенного файлового менеджера
1. **Загрузка файлов (Drag & Drop)**: Поддержка перетаскивания и стандартного окна выбора файлов. Отображается визуальный прогресс-бар загрузки.
2. **Скачивание и удаление файлов**.
3. **Переименование и перемещение** файлов в другие директории (через контекстные кнопки).
4. **Создание директорий (папок)** и навигация по ним.
5. **Миниатюры (Предпросмотр)** (размер 300x300):
   - Если рядом с файлом `.gcode` лежит картинка `.png` или `.jpg` с таким же именем, она выводится как миниатюра.
   - Если миниатюры файла нет, ищется `logo.png` или `logo.jpg` в корне SD-карты.
   - Если и логотип отсутствует — выводится генерируемая SVG-заглушка 300x300.
