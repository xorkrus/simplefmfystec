# Simple File Manager for FYSETC SD WIFI Card (ESP8285)
Простой файловый менеджер для устройства SD WIFI FYSETC на базе ESP8285 с веб-интерфейсом.

## Возможности веб-интерфейса

1. **Загрузка файлов** - перетаскиванием (drag & drop) или выбором через диалог, с визуализацией прогресса загрузки
2. **Удаление файлов** и директорий
3. **Переименование файлов**
4. **Создание директорий**
5. **Перемещение файлов** между директориями
6. **Скачивание файлов** на компьютер
7. **Предпросмотр G-code файлов**:
   - Если рядом с файлом `.gcode` есть `.jpg`/`.png` с таким же именем - отображается эта миниатюра
   - Если нет - ищется `logo.jpg`/`logo.png` в корне карты
   - Если нет и такого - отображается встроенная заглушка
   - Размер миниатюры: 300x300 пикселей

## Прошивка
### Стандартный режим
- При запуске проверяется наличие файла `index.html` на SD карте
- Если файл существует - используется как главная страница веб-интерфейса
- Если файла нет - используется встроенный fallback интерфейс

### WiFi подключение
1. Сначала загружаются настройки из `SETUP.INI` на SD карте
2. Попытка подключения к указанной сети
3. Если подключение не удалось в течение 15 секунд - автоматически включается режим точки доступа

### Точка доступа (AP Mode)
- **SSID**: `sd-card-3dp`
- **Пароль**: `12345678`

## Настройка WiFi
Создайте файл `SETUP.INI` в корне SD карты со следующим содержимым:
```ini
[WIFI]
SSID=ваша_сеть
PASSWORD=ваш_пароль
