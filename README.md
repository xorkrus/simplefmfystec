FYSETC SD WIFI File Manager (ESP8285)

Прошивка для устройства SD WIFI FYSETC, превращающая его в простой файловый менеджер для SD-карты через веб-интерфейс.
Основной функционал

    Загрузка файлов: Перетаскиванием (Drag & Drop) или через кнопку выбора. Присутствует визуализация прогресса загрузки.
    Управление файлами: Удаление, переименование, перемещение файлов и создание директорий.
    Скачивание: Прямое скачивание файлов из браузера.
    Умные миниатюры (300x300): 
        Если рядом с .gcode файлом находится .jpg или .png с таким же именем — выводится предпросмотр модели.
        Если нет — выводится logo.png или logo.jpg из корня SD-карты.
        Если нет и логотипа — выводится серая заглушка.

Настройка сети (WIFI)

При запуске устройство ищет в корне SD-карты файл SETUP.INI.Формат файла строго следующий:

[WIFI]SSID=имя_вашей_сетиPASSWORD=пароль_от_сети

Если файл отсутствует, формат нарушен или не удалось подключиться к указанной сети, устройство запускает собственную точку доступа:

     SSID: sd-card-3dp
     PASSWORD: 12345678

Кастомизация интерфейса

Прошивка содержит встроенный (fallback) веб-интерфейс. 
Если вы поместите в корень SD-карты свой собственный файл index.html, устройство будет отдавать его вместо встроенного. Взаимодействие с SD-картой в вашем интерфейсе должно происходить через API запросы (Endpoints описаны в исходном коде main.cpp).
Аппаратная часть (Распиновка)

Устройство использует следующие пины (изменению не подлежит):

     SD_CS (GPIO 4)
     MISO (GPIO 12)
     MOSI (GPIO 13)
     SCLK (GPIO 14)
     CS_SENSE (GPIO 5) - определение занятости шины Marlin
     LED (GPIO 2) - индикатор работы/ошибок

Сборка

Для сборки используется PlatformIO. Достаточно клонировать репозиторий и запустить:
pio run
Для прошивки:
pio run --target upload
