# simplefmfystec

Прошивка для FYSETC SD WIFI (ESP8285) — простой веб-файловый менеджер для SD-карты 3D-принтера.

## Возможности

- **Загрузка файлов** через Drag & Drop или кнопку выбора с индикацией прогресса.
- **Управление файлами**: удаление, переименование, создание папок, скачивание.
- **Умные миниатюры**: автоматический предпросмотр `.gcode` (ищет рядом `.jpg`/`.png` или `logo.jpg`/`logo.png`).
- **Адаптивный интерфейс** — отдельные версии для десктопа и мобильных устройств.
- **Настройка WiFi** через файл `SETUP.INI` на SD-карте, fallback-сеть или режим точки доступа.
- **LED-индикация** состояний.

## Аппаратная часть

| Пин      | Назначение                     |
|----------|--------------------------------|
| GPIO 4   | SD_CS (выбор SD-карты)        |
| GPIO 12  | MISO                           |
| GPIO 13  | MOSI                           |
| GPIO 14  | SCLK                           |
| GPIO 5   | CS_SENSE (занятость шины)      |
| GPIO 2   | LED (индикатор)                |
